# Pydoro

A streamlined Python-based Pomodoro timer designed for focused productivity. It integrates terminal controls with a floating graphical countdown and automated session analytics to help track and optimize daily workflow.

## Key Features

* **Customizable Time Management:** Configure exact work and break durations directly through the terminal interface.
* **Persistent HUD Timer:** Utilizes a lightweight, always-on-top graphical window to display the active countdown without disrupting the primary workspace.
* **Automated Analytics:** Logs daily sessions, categorizes time spent by subject, and generates performance reports to identify productivity trends.

## Project Structure

* `main.py` — Manages the primary command-line interface and session orchestration.
* `timer_window.py` — Controls the floating graphical display and countdown mechanics.
* `tracker.py` — Handles data logging, session aggregation, and report generation.
